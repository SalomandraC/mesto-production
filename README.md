#Mesto
Учебный проект Яндекс Практикума — страница для публикации фотографий. 3 вариант задания.

##Сделано
-Редактирование имени, описания и аватара пользователя.
-Добавление карточек с фотографиями.
-Удаление своих карточек с подтверждением.
-Постановка и снятие лайков, отображение их количества.
-Просмотр фотографий в увеличенном размере.
-Валидация форм.
-Просмотр статистики карточек по клику на логотип.
-Сохранение данных на сервере через API.
